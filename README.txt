Wearwise PWA v5 — Custom outfits

Upload index.html, manifest.json, sw.js, icon-192.png, and icon-512.png to the root of your existing public GitHub Pages repository, replacing the older versions.

Create outfits from your own clothes in the My outfits tab, save them, and use Mark outfit worn to update per-item wear counts and wear history. Custom outfits are included in compact JSON backups. Existing local storage key is preserved. Export a compact JSON backup before updating.
